# Security policy

## Reporting a vulnerability

Report a vulnerability through this repository's private vulnerability reporting: open the
Security tab and choose "Report a vulnerability". Do not describe a vulnerability in a
public issue or pull request.

Please include:

- what the problem is and which app or file it affects
- steps to reproduce it, or a proof of concept
- the impact you expect
- any fix you suggest

## Scope

The code in this repository and the public site built from it are in scope. Please do not
test against the live site in ways that degrade it for other people.

## Response

This is a personal project. There is no promised response time and no bounty.
