The drawer is noted as story order. Here are the four real seed cases compared. Ink is NTSB data, magenta is AI-extracted. Values that are the same in every case collapse into one line at the bottom instead of repeating.

1 · Flight strips

Each case is a strip, like an ATC flight progress strip, stacked so the same field lines up down the page. Easy to scan one question ("how long since maintenance?") across all four. Sortable.
