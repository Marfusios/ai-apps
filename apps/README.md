# Applications

Each application lives in its own directory and includes everything needed to
install, configure, run, and test it. Apps can use different languages and frameworks.

Create a scaffold with `python3 scripts/new_app.py <app-name>` from the repository root.

| App | Purpose | Status |
| --- | --- | --- |
| [AirCase](aviation-investigations/README.md) (`apps/aviation-investigations`) | Evidence-based search and comparison of NTSB investigations, an aviation casebook. Live with keyword search, an AI evidence search and a daily automatic NTSB import; generated summaries stay off. | Ready |

implementation pending), **Experimental**
