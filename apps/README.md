# Applications

Each application lives in its own directory and includes everything needed to
install, configure, run, and test it. Apps can use different languages and frameworks.

Create a scaffold with `python3 scripts/new_app.py <app-name>` from the repository root.

| App | Purpose | Status |
| --- | --- | --- |
| [Aviation Casebook](aviation-investigations/README.md) | Evidence-based search and comparison of NTSB investigations. | Experimental |

Status meanings: **Scaffold** (starting documentation), **Design** (researched proposal,
implementation pending), **Experimental**
(runnable with limitations), and **Ready** (documented and covered by meaningful tests).
